# Verification Scope

This repository is the public category surface for Elyria consequence-boundary infrastructure.

It defines the shared architecture and invariant vocabulary. Executable proof remains corridor-specific.

## Canonical rule

`proposed motion -> governing boundary -> current standing -> admissibility -> protected-effect posture -> receipt -> replay`

A category statement is not itself implementation evidence.

## Evidence discipline

Each vertical corridor must identify:

- the governed movement;
- the protected consequence;
- the admissibility inputs;
- the fail-closed outcomes;
- the receipt/proof artifact;
- the replay or verification procedure;
- the environment and limitations of the proof.

## Claim boundary

No public corridor should be represented as production-certified, universally safe, third-party validated, or complete merely because the shared category repository exists.
